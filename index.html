📖 ۱. مقدمه و مفاهیم پایه

  • معرفی دوره و اهداف
  • آشنایی با کنترل نسخه (Version Control)
  • تاریخچه و اهمیت نگهداری نسخه‌های مختلف
  • ابزارهای diff و patch – استخراج و اعمال تغییرات
  • کاربرد عملی diff و patch در مدیریت فایل‌ها

💡 در این بخش با مفاهیم بنیادین سیستم‌های کنترل نسخه و ابزارهای خط فرمان مرتبط آشنا می‌شوید.

🐙 ۲. آشنایی با Git

  • Git چیست و چه تفاوتی با سایر VCSها دارد؟
  • نصب و راه‌اندازی Git روی سیستم‌عامل‌های مختلف
  • اولین قدم‌ها: ایجاد مخزن (init)، افزودن فایل (add) و ثبت تغییرات (commit)
  • ردیابی فایل‌ها و مشاهده وضعیت مخزن
  • گردش کار پایه Git – کار با Staging Area
  • ساختار و اصول نوشتن پیام commit

📌 پس از این بخش، می‌توانید مخزن محلی ایجاد کرده و تغییرات خود را به‌صورت commit ثبت کنید.

⚙️ ۳. کار پیشرفته با Git

  • رد کردن Staging Area با استفاده از git commit -a
  • دریافت اطلاعات دقیق از تغییرات (git log، git diff)
  • حذف و تغییر نام فایل‌ها با git rm و git mv

💡 این مباحث به شما کمک می‌کند کارایی بیشتری در کار روزمره با Git داشته باشید.

↩️ ۴. بازگردانی تغییرات

  • لغو تغییرات قبل از commit (git restore)
  • اصلاح آخرین commit با git commit --amend
  • بازگشت به نسخه‌های قبلی با git revert و git reset
  • شناسایی commitها با هش و ارجاعات نسبی

⚠️ با روش‌های امن و پرخطر بازگردانی تغییرات آشنا می‌شوید تا بتوانید اشتباهات را به‌درستی مدیریت کنید.

🌿 ۵. شاخه‌ها (Branches) و ادغام (Merging)

  • شاخه چیست و چرا از آن استفاده می‌کنیم؟
  • ایجاد و جابه‌جایی بین شاخه‌ها (git branch و git switch)
  • کار با چند شاخه به‌طور همزمان
  • ادغام شاخه‌ها با git merge
  • مدیریت تعارضات (Merge Conflicts) و حل آن‌ها

📌 این بخش برای کار تیمی بسیار حیاتی است و شما را با الگوهای رایج توسعه آشنا می‌کند.

🐙 ۶. کار با مخازن راه‌دور (GitHub)

  • معرفی GitHub و امکانات آن
  • تعامل پایه با GitHub – clone، push، pull
  • مفهوم Remote و مدیریت آن‌ها
  • واکشی تغییرات جدید با git fetch
  • به‌روزرسانی مخزن محلی با git pull
  • SSH و API Keys – اتصال امن به GitHub

💡 با این مباحث، پروژه‌های خود را به GitHub متصل کرده و با دیگران به اشتراک می‌گذارید.

⚡ ۷. حل تعارضات و همکاری پیشرفته

  • گردش کار Pull-Merge-Push در همکاری تیمی
  • ارسال شاخه‌ها به مخزن راه‌دور (git push)
  • ری‌بیس (Rebase) و کاربردهای آن
  • مقایسه ری‌بیس با ادغام (merge)
  • بهترین روش‌های همکاری با Git و GitHub

⚠️ ری‌بیس ابزاری قدرتمند است، اما باید با احتیاط از آن استفاده کرد تا تاریخچه پروژه دچار مشکل نشود.

🤝 ۸. همکاری تیمی با GitHub

  • گردش کار Pull Request – ایجاد، بررسی و به‌روزرسانی
  • فشرده‌سازی commitها (Squash) قبل از ادغام
  • کد بازبینی (Code Review) و اهمیت آن
  • مدیریت پروژه با GitHub – Issueها و Project Board
  • یکپارچه‌سازی مداوم (Continuous Integration) با GitHub Actions

📌 این بخش شما را برای مشارکت در پروژه‌های متن‌باز و تیم‌های نرم‌افزاری آماده می‌کند.

🎓 ۹. جمع‌بندی و ادامه مسیر

  • مرور مهارت‌های کسب‌شده
  • ارتباط با هم‌دوره‌ای‌ها و به‌اشتراک‌گذاری تجربیات
  • نگاهی به دوره‌های بعدی و مسیر یادگیری

🎉 با اتمام این دوره، شما به یک کاربر حرفه‌ای Git و GitHub تبدیل خواهید شد.
